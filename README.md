# The Learning Haven

Loveable Prompt — Premium Tutoring Website

⸻

Project Overview

Create a fully responsive (mobile-first) tutoring website for a modern educational brand. The website should feel warm, calm, optimistic, approachable and premium, taking inspiration from the emotional experience and simplicity of Headspace, while remaining 100% original in its branding, layouts, illustrations, animations, components and overall identity.

Do NOT copy Headspace. Instead, capture the same feeling:

* Calm
* Friendly
* Human
* Hopeful
* Encouraging
* Minimal
* Beautiful
* Easy to use

The website should feel like a premium educational platform rather than a traditional tutoring website.

Overall Goal

Create a tutoring website that doesn’t feel like a tutoring website.

It should feel calming, modern, and thoughtfully designed—something parents enjoy using and immediately trust. The booking experience should be effortless, the design should be memorable without being flashy, and the brand should communicate genuine care for helping learners grow in confidence and achieve better results.
